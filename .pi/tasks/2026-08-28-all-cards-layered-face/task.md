# 全部卡牌统一连续底图、英雄居中与牌库状态

## 目标与决策

- 将战场、手牌、发现选项、拖拽预览和检查浮层中的所有公开卡牌统一为当前 `?card-preview` 样本的视觉：整张官方卡图作为连续底图，原始卡名与效果文字由图片保留，费用/攻击/生命或耐久由实时公开投影覆盖。
- 复用现有 `CardFace` 作为 GameBoard 全部卡牌入口，保持 `data-card-*`、可访问名称、拖拽、发现和 inspection 契约；移除重复的自制卡名/关键词正文层。
- 双方英雄区使用同一三列结构：头像位于各自英雄条水平中心，英雄技能固定在头像右侧；法力区按锁定官方截图的蓝色水晶胶囊样式重建，当前/最大/临时法力继续来自公开投影。
- 战场右侧新增本地官方牌背牌库面板，使用公开 `deckCount`/手牌数量并区分有牌与空牌状态。
- 保持引擎、投影和卡牌数据不变，所有动态 UI 数值继续来自公开投影或现有卡牌 registry。

## 计划

1. 盘点 CardPreview 与 GameBoard 的卡牌渲染入口、素材尺寸、英雄公开字段、牌库投影和测试选择器。
2. 调整共享 `CardFace` 与卡牌 CSS，使所有公开卡面保留原图全文并使用同一费用/属性覆盖几何。
3. 调整英雄三列布局与牌库状态组件，补充对称、牌背、实时数量和空牌分支的回归断言。
4. 执行组件测试、App 集成测试、类型、lint、architecture、build。
5. 使用预览服务进行 1280×720、1920×1080、390px、牌库悬停和 Discover/inspection 真实浏览器检查，跑 M1/M3/M4 定向门禁。
