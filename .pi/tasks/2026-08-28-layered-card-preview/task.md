# 分层卡牌预览原型

## 目标与决策

- 先制作一张独立的真实卡牌预览，供主人确认高保真视觉方向。
- 选用 `CS2_196`「剃刀猎手」作为样本，覆盖费用、攻击、生命、随从类型和完整战吼文案。
- 预览采用完整官方卡框/标题带/原画/效果文字作为连续底图，仅覆盖费用、攻击、生命三个动态数值区域；动态数值由本地预览状态控制，后续可接入公开 projection。
- 通过 `?card-preview` 进入独立预览页，保持现有战场流程和规则引擎边界不变。

## 计划

1. 读取现有卡牌数据、素材尺寸、App 入口与测试 harness。
2. 新增独立 CardPreview 组件、原始卡图展示和动态数值控件。
3. 接入 `?card-preview` 查询入口，补充组件契约测试和预览样式。
4. 运行目标 Vitest、typecheck、lint、build，并用浏览器检查预览页面。

## 验证记录

- `pnpm exec vitest run src/ui/card/CardPreview.test.tsx src/app/App.test.tsx`：2 个文件 / 6 个测试通过。
- `pnpm run typecheck`、`pnpm run lint`、`pnpm run build`：全部通过，构建产物含独立卡牌预览入口。
- 真实浏览器 `http://127.0.0.1:4174/?card-preview`：1280×720 页面滚动高度等于视口；费用 3→4、攻击 2→3、生命 3→2 的动态层验证通过；费用覆盖层放大至卡面宽度 21%，原画与效果来源为 `/assets/cards/CS2_196.png`，原始效果文案“战吼：召唤一个1/1的野猪。”完整保留；最终截图确认旧数值被覆盖，原卡框与正文保持连续。控制台错误数为 0。

## 结论

已完成独立的 `CS2_196`「剃刀猎手」卡牌预览。它直接使用本地真实卡图的原画、卡框、标题和效果文字，仅覆盖费用、攻击、生命三个动态数值；`?card-preview` 仅作为预览入口，现有战场与规则引擎保持不变。
